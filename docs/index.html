RatMath Shelf

A shelf of subject libraries, each built on exact numbers.

One library for each part of mathematics, for JavaScript. Each one gives a fast preview first and then an answer that is exact, or an interval proven to contain the truth. This page lists what is on the shelf today and what is planned. To have all of it in one import, use the ratmath package.

The foundation

Everything on the shelf stands on Core.

RatMath Core

@ratmath/core

Exact integers, fractions and rational intervals for JavaScript, with certified approximations, regions, number literals in any base and the R template for writing exact expressions. BigInt-based, with no dependencies.

Documentation Explore Reference npm Source

CoreThe R template →
R`1/3 + 1/6`        // 1/2, exactly
R`0.#3`             // 1/3
R`1.2[3:6]`         // 1.23 to 1.26

How the shelf is kept

Every library has the same shape: an overview, a page to explore it without writing code, a detailed reference, and a page for each topic that explains the usage and the mathematics and ends with a runnable code box.

A topic appears under “On the shelf” only when it is built and its page exists. Until then it stays under “Planned” and in the roadmap.
