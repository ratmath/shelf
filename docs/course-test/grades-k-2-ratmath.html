  6. 6.Place valuePartly
    In the number 486, what is the value of the digit 8?
    Independent answer
    80 (eight tens).
    RatMath code
    R`486`.floorDivide(R`10`).modulo(R`10`).multiply(R`10`)
    Output
    80
    Core has no digit or place-value helper; the code takes the tens digit with integer division and remainder, which is the arithmetic behind place value rather than the idea itself.

  8. 8.RoundingDisagrees
    Round 65 to the nearest ten.
    Independent answer
    70 (a 5 in the ones place rounds up).
    RatMath code
    new Rational(65n).roundTo(-1)
    Output
    60
    Independent answer, in RatMath's notation
    70
    Core rounds half to even unless told otherwise, so 65 goes to 60; school rounding is half up, roundTo(-1, "half-up"), which gives 70. Not a bug, but the default surprises anyone checking school work. (Also: Rational#round() and floor() return a bigint, not an Integer, so .multiply cannot follow them.)

  12. 12.TimePartly
    What time is it 45 minutes after 2:30?
    Independent answer
    3:15.
    RatMath code
    const later = units.Q("150 min").add(units.Q("45 min"));   // minutes after 12:00
const h = later.to("h");
PRINT(h);
[new Integer(h.value.floor()), later.to("min").value.subtract(R`180`)]
    Output
    [3, 15]
    Units convert 195 minutes to 13/4 hours exactly, but there is no clock time: reading 13/4 h as 3:15 is done by hand.

  20. 20.Picture graphAgrees
    A class graph shows 5 cats, 8 dogs and 3 fish as pets. How many pets are there in all, and how many more dogs than fish?
    Independent answer
    16 pets in all; 5 more dogs than fish.
    RatMath code
    const pets = { cats: 5, dogs: 8, fish: 3 };
[stats.sum(Object.values(pets)), R`${pets.dogs} - ${pets.fish}`]
    Output
