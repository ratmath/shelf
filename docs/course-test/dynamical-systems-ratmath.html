  1. 1.Fixed points and stabilityAgrees
    Find the fixed points of the logistic map f(x)=3x(1−x)f(x) = 3x(1 - x)f(x)=3x(1−x) and classify them.
    Independent answer
    x=3x−3x2x = 3x - 3x^2x=3x−3x2: x=0x = 0x=0 or x=23x = \tfrac23x=32​. f′(x)=3−6xf'(x) = 3 - 6xf′(x)=3−6x: f′(0)=3f'(0) = 3f′(0)=3 (repelling), f′(23)=−1f'(\tfrac23) = -1f′(32​)=−1 (neutral: the boundary where the period doubling starts).
    RatMath code

    Output

  18. 18.Game of LifeAgrees

    Independent answer
