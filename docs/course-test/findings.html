Disagreements (1)

DisagreesGrades K–2: number sense and early arithmetic 8
Rounding
Core rounds half to even unless told otherwise, so 65 goes to 60; school rounding is half up, roundTo(-1, "half-up"), which gives 70. Not a bug, but the default surprises anyone checking school work; the Rationals docs now say so first. roundInteger("half-up") returns a Core Integer, so .multiply can follow.
