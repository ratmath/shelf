  1. 1.Dot and cross productsPartly
    For u=(1,2,−2)\mathbf u = (1, 2, -2)u=(1,2,−2) and v=(3,0,4)\mathbf v = (3, 0, 4)v=(3,0,4) find u⋅v\mathbf u\cdot\mathbf vu⋅v and u×v\mathbf u\times\mathbf vu×v.
    Independent answer
    u⋅v=3−8=−5\mathbf u\cdot\mathbf v = 3 - 8 = -5u⋅v=3−8=−5; u×v=(8,−10,−6)\mathbf u\times\mathbf v = (8, -10, -6)u×v=(8,−10,−6).
    RatMath code
    const u = [1, 2, -2], v = [3, 0, 4];
const minor = (i, j) => linalg.det([[u[i], u[j]], [v[i], v[j]]]).exact();
[linalg.multiply([u], v.map((x) => [x])), [minor(1, 2), minor(2, 0), minor(0, 1)]]
    Output
    [[[-5]], [8, -10, -6]]
    No library has a cross product in three dimensions (geo's cross is the planar one, and is not exported). The dot product is a 1×3 by 3×1 matrix product, and the cross product is built from 2×2 determinants by hand.
