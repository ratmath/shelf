  1. 1.TautologyAgrees
    Is ((p→q)∧(q→r))→(p→r)((p \to q) \land (q \to r)) \to (p \to r)((p→q)∧(q→r))→(p→r) a tautology?
    Independent answer
    Yes (hypothetical syllogism): the only way to make p→rp \to rp→r false is ppp true, rrr false, and then one of the hypotheses is false.
    RatMath code
    logic.classify("((p -> q) & (q -> r)) -> (p -> r)").kind
    Output
    tautology
  2. 2.De MorganAgrees
    Show that ¬(p∧q)≡¬p∨¬q\lnot(p \land q) \equiv \lnot p \lor \lnot q¬(p∧q)≡¬p∨¬q.
    Independent answer
    Both are false exactly when ppp and qqq are both true.
    RatMath code
    logic.equivalent("!(p & q)", "!p | !q").status
    Output

  15. 15.Shortest pathAgrees

    RatMath code

const p = discrete.shortestPath(g, "A", "E");
[p.path, p.distance]
    Output
    [["A", "C", "B", "D", "E"], 10]
