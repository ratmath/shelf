Game theory: test

TestIndependent answersRatMath answers

The prisoner's dilemma, matching pennies and rock–paper–scissors, a 2×2 zero-sum game solved by mixing, saddle points, the battle of the sexes with its mixed equilibrium, an entry game by backward induction, Nim and the Sprague–Grundy values of a subtraction game, short partizan games, the glove game's Shapley value and core, Shapley–Shubik and Banzhaf power, plurality, Borda and Condorcet winners, Gale–Shapley matching, Hamilton apportionment and the assignment problem.

Twenty exercises of the kind this course sets. Answers are on the independent answers page; the same exercises done with RatMath are on the RatMath answers page.

  1. 1.Prisoner's dilemma
    Each prisoner can Cooperate or Defect. Payoffs (row, column): CC (−1,−1)(-1, -1)(−1,−1), CD (−3,0)(-3, 0)(−3,0), DC (0,−3)(0, -3)(0,−3), DD (−2,−2)(-2, -2)(−2,−2). Find the pure Nash equilibria.
  2. 2.Matching pennies
    Solve the zero-sum game (1−1−11)\begin{pmatrix}1&-1\\-1&1\end{pmatrix}(1−1​−11​).
  3. 3.A 2×2 zero-sum game
    Solve the zero-sum game (3−1−24)\begin{pmatrix}3&-1\\-2&4\end{pmatrix}(3−2​−14​).
  4. 4.Saddle points
    Find the saddle points of (42310−1512)\begin{pmatrix}4&2&3\\1&0&-1\\5&1&2\end{pmatrix}​415​201​3−12​​.
  5. 5.Rock, paper, scissors
    Solve rock–paper–scissors as a zero-sum game (win 1, lose −1-1−1, tie 0).
  6. 6.Battle of the sexes
    Row payoffs (2001)\begin{pmatrix}2&0\\0&1\end{pmatrix}(20​01​), column payoffs (1002)\begin{pmatrix}1&0\\0&2\end{pmatrix}(10​02​). Find all Nash equilibria.
  7. 7.Backward induction
    An entrant E chooses Out (payoffs E 0, incumbent I 2) or In. After In, I chooses Fight (−1,−1-1, -1−1,−1) or Accommodate (1, 1). Find the subgame perfect equilibrium.
  8. 8.Nim
    In Nim with heaps 3, 4, 5, is the first player winning? Give a winning move.
  9. 9.Sprague–Grundy values
    In the subtraction game where a move removes 1, 2 or 3 counters, find the Grundy values of heaps 0 to 11.
  10. 10.Partizan games
    Find the values of the games {0∣ }\{0 \mid\ \}{0∣ }, { ∣0}\{\ \mid 0\}{ ∣0} and {0∣0}\{0 \mid 0\}{0∣0}.
  11. 11.Shapley value
    In the glove game, player L owns a left glove and R1, R2 each own a right glove; a coalition is worth 1 if it can make a pair. Find the Shapley value.
  12. 12.The core
    Find the core of the glove game.
  13. 13.Voting power
    Three voters have weights 50, 49, 1 and the quota is 51. Find the Shapley–Shubik and Banzhaf power indices.
  14. 14.Voting methods
    Nine voters: 4 rank A > B > C, 3 rank B > C > A, 2 rank C > B > A. Find the plurality, Borda and Condorcet winners.
  15. 15.Stable matching
    Proposers A: x > y and B: y > x; receivers x: B > A and y: A > B. Run Gale–Shapley with A and B proposing.
  16. 16.Apportionment
    Apportion 10 seats among states of population 120, 230 and 650 by Hamilton's method.

  20. 20.Pure equilibria
