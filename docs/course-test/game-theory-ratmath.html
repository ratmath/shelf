  1. 1.Prisoner's dilemmaAgrees
    Each prisoner can Cooperate or Defect. Payoffs (row, column): CC (−1,−1)(-1, -1)(−1,−1), CD (−3,0)(-3, 0)(−3,0), DC (0,−3)(0, -3)(0,−3), DD (−2,−2)(-2, -2)(−2,−2). Find the pure Nash equilibria.
    Independent answer
    Defect strictly dominates Cooperate for both (0>−10 > -10>−1, −2>−3-2 > -3−2>−3), so the only equilibrium is (D, D), paying (−2,−2)(-2, -2)(−2,−2).
    RatMath code
    const g = discrete.bimatrixGame([[-1, -3], [0, -2]], [[-1, 0], [-3, -2]], { rows: ["C", "D"], columns: ["C", "D"] });
g.equilibria().map(String)
    Output
    ["(D; D) paying -2 and -2"]

  7. 7.Backward inductionAgrees
    An entrant E chooses Out (payoffs E 0, incumbent I 2) or In. After In, I chooses Fight (−1,−1-1, -1−1,−1) or Accommodate (1, 1). Find the subgame perfect equilibrium.
    Independent answer
    After In, I prefers Accommodate (1>−11 > -11>−1); knowing that, E prefers In (1>01 > 01>0). Play: In, Accommodate, payoffs (1, 1). The threat to fight is not credible.
    RatMath code
    const tree = { player: "E", moves: {
  out: { payoff: { E: 0, I: 2 } },
  in: { player: "I", moves: { fight: { payoff: { E: -1, I: -1 } }, accommodate: { payoff: { E: 1, I: 1 } } } },
} };
const b = discrete.backwardInduction(tree);
[b.path, ((o) => Object.fromEntries(Object.entries(o).map(([k, v]) => [k, String(v)])))(b.value)]
    Output
    [["in", "accommodate"], { E: "1", I: "1" }]

  11. 11.Shapley valueAgrees
    In the glove game, player L owns a left glove and R1, R2 each own a right glove; a coalition is worth 1 if it can make a pair. Find the Shapley value.
    Independent answer
    L is pivotal unless it comes first (in 4 of 6 orders): 23\tfrac2332​. R1 is pivotal only in the order L, R1, R2: 16\tfrac1661​; likewise R2.
    RatMath code
    const g = discrete.cooperativeGame(["L", "R1", "R2"], (S) => (S.includes("L") && (S.includes("R1") || S.includes("R2")) ? 1 : 0));
((o) => Object.fromEntries(Object.entries(o).map(([k, v]) => [k, String(v)])))(discrete.shapley(g))
    Output
    { L: "2/3", R1: "1/6", R2: "1/6" }
  12. 12.The corePartly

  14. 14.Voting methodsAgrees
    Nine voters: 4 rank A > B > C, 3 rank B > C > A, 2 rank C > B > A. Find the plurality, Borda and Condorcet winners.
    Independent answer
    Plurality: A (4 first places). Borda (2, 1, 0 points): A 8, B 12, C 7, so B. Pairwise: B beats A 5–4 and C 7–2, so B is the Condorcet winner.
    RatMath code
    const b = [{ count: 4, ranking: ["A", "B", "C"] }, { count: 3, ranking: ["B", "C", "A"] }, { count: 2, ranking: ["C", "B", "A"] }];
[discrete.plurality(b).winners, discrete.borda(b).winners, discrete.condorcet(b).winner]
    Output
    [["A"], ["B"], "B"]
