  1. 1.Finite topologies
    How many topologies are there on a three-point set?
    Answer
    Topologies on a finite set correspond to preorders (reflexive, transitive relations), via x≤yx \le yx≤y iff every open set containing xxx contains yyy. On 3 points there are 29.
  2. 2.Metrics
    Describe the unit ball of the taxicab metric d(p,q)=∣p1−q1∣+∣p2−q2∣d(p, q) = |p_1 - q_1| + |p_2 - q_2|d(p,q)=∣p1​−q1​∣+∣p2​−q2​∣ in the plane. What is its "π\piπ" (half the perimeter of the unit circle, measured in the same metric)?
    Answer
    The square with vertices (±1,0)(\pm1, 0)(±1,0), (0,±1)(0, \pm1)(0,±1). Each side has taxicab length 2, so the perimeter is 8 and πtaxi=4\pi_{taxi} = 4πtaxi​=4.
  3. 3.A bounded metric
    Show d′(x,y)=∣x−y∣1+∣x−y∣d'(x, y) = \dfrac{|x - y|}{1 + |x - y|}d′(x,y)=1+∣x−y∣∣x−y∣​ is a metric on R\mathbb RR giving the same topology.
    Answer
    t↦t/(1+t)t \mapsto t/(1 + t)t↦t/(1+t) is increasing, subadditive and zero only at 0, so the triangle inequality passes from ∣x−y∣|x - y|∣x−y∣ to d′d'd′. Small balls of the two metrics nest inside each other, so the open sets agree.
  4. 4.Connectedness and compactness
    Is [0,1][0, 1][0,1] compact? Is (0,1)(0, 1)(0,1)? Is Q\mathbb QQ connected?
    Answer
    [0,1][0, 1][0,1] is compact (Heine–Borel); (0,1)(0, 1)(0,1) is not (the cover (1/n,1)(1/n, 1)(1/n,1) has no finite subcover). Q\mathbb QQ is totally disconnected: (−∞,2)∩Q(-\infty, \sqrt2) \cap \mathbb Q(−∞,2​)∩Q and (2,∞)∩Q(\sqrt2, \infty) \cap \mathbb Q(2​,∞)∩Q separate it.
  5. 5.Winding numbers
    Find the winding number about 0 of the closed polygon 1→i→−1→−i→11 \to i \to -1 \to -i \to 11→i→−1→−i→1, of the same path traversed twice, and of the triangle 3→3+i→2+i→33 \to 3 + i \to 2 + i \to 33→3+i→2+i→3.
    Answer
    Once round counter-clockwise: 1. Twice: 2. The triangle does not surround 0: 0.

  14. 14.Classification of surfaces
