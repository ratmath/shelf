  1. 1.Deterministic automataAgrees
    Design a DFA over {0,1}\{0, 1\}{0,1} accepting words with an even number of 1s. Does it accept 1011? 1001?
    Independent answer
    Two states, even (start, accepting) and odd, swapped by each 1. 1011 has three 1s: rejected. 1001 has two: accepted.
    RatMath code
    const M = logic.automaton({ states: ["e", "o"], alphabet: "01", start: "e", accept: ["e"],
  delta: { e: { 0: "e", 1: "o" }, o: { 0: "o", 1: "e" } } });
[M.accepts("1011"), M.accepts("1001")]
    Output
    [false, true]
  2. 2.Minimal DFAAgrees
    How many states does the minimal DFA for binary words ending in 01 have?
    Independent answer
    It must remember whether the word ends in nothing useful, in 0, or in 01: three states, which are pairwise distinguishable (by the suffixes 01, 1, and ε\varepsilonε).
    RatMath code
    logic.minimizeAutomaton(logic.toDFA(logic.regexToNFA("(0|1)*01"))).states.length
    Output
    3
  3. 3.Subset constructionAgrees
    Convert (a∣b)∗abb(a|b)^*abb(a∣b)∗abb to a DFA and minimise it. How many states? Does it accept aababbaababbaababb and abababababab?
    Independent answer
    The minimal DFA tracks the longest suffix that is a prefix of abbabbabb: ε,a,ab,abb\varepsilon, a, ab, abbε,a,ab,abb: 4 states. aababbaababbaababb ends in abbabbabb: yes; abababababab: no.
    RatMath code

[D.states.length, D.accepts("aababb"), D.accepts("abab")]
    Output
    [4, true, false]
  4. 4.Equivalent regular expressionsAgrees

    Independent answer

  5. 5.Product constructionAgrees
    Build an automaton for words over {a,b}\{a, b\}{a,b} with an even number of aaas and an odd number of bbbs. Test aabaabaab and ababab.
    Independent answer
    Pair the two 2-state parity automata: 4 states, accepting (even, odd). aabaabaab: 2 aaas, 1 bbb: yes. ababab: no.
    RatMath code
    const par = (letter, acc) => logic.automaton({ states: ["e", "o"], alphabet: "ab", start: "e", accept: [acc],
  delta: { e: { a: letter === "a" ? "o" : "e", b: letter === "b" ? "o" : "e" }, o: { a: letter === "a" ? "e" : "o", b: letter === "b" ? "e" : "o" } } });
const P = logic.product(par("a", "e"), par("b", "o"));
[P.states.length, P.accepts("aab"), P.accepts("ab")]
    Output
    [4, true, false]

  10. 10.Pumping lemmaCan't yet
    Prove that {anbn}\{a^nb^n\}{anbn} is not regular.
    Independent answer
    If it were, with pumping length ppp, write apbp=xyza^pb^p = xyzapbp=xyz with ∣xy∣≤p|xy| \le p∣xy∣≤p, ∣y∣≥1|y| \ge 1∣y∣≥1. Then y=aky = a^ky=ak, and xy2z=ap+kbpxy^2z = a^{p+k}b^pxy2z=ap+kbp is not in the language. Contradiction.
    RatMath code
    // No proof tool: a finite check only. The minimal DFA for words a^n b^n with n ≤ N needs more states as N grows.

  11. 11.Turing machinesAgrees
    Run a Turing machine that adds one to a binary number on the input 1011.
    Independent answer

    RatMath code

[r.status, r.tape]
    Output
    ["accepted", "1100"]

  15. 15.The halting problemCan't yet
    Is there an algorithm that decides, for every program and input, whether the program halts?
    Independent answer
    No (Turing). If HHH decided halting, the program DDD that runs HHH on its own code and does the opposite would halt exactly when it does not.
    RatMath code
    // A run with a budget can only report "running" for a machine that has not stopped yet.
const loop = logic.turing({ start: "s", accept: "y", reject: "n", delta: { "s,_": ["s", "_", "R"] } });
loop.run("", { budget: 1000 }).status
    Output
    running
    Independent answer, in RatMath's notation
    undecidable (a proof)
    No computation can stand in for the diagonal argument; run with a budget reports running, as the documentation says it must.

  17. 17.Ripple-carry adderPartly
    How many gates and what depth does a ripple-carry adder for 4-bit numbers have, built from full adders of 5 gates and depth 3?
    Independent answer
    Four full adders: about 20 gates; the carry passes through each stage, so the depth grows linearly (roughly 2n+1=92n + 1 = 92n+1=9 for the carry chain).
    RatMath code
    const c = logic.adders.ripple(4);
[c.size, c.depth]
    Output
    [17, 7]
    The exact counts depend on how the half and full adders are built; the check accepts the textbook range.
