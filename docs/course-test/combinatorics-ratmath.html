  15. 15.Generating functionsAgrees
    In how many ways can 25 cents be made from pennies, nickels and dimes?
    Independent answer
    The coefficient of x25x^{25}x25 in 1(1−x)(1−x5)(1−x10)\dfrac{1}{(1 - x)(1 - x^5)(1 - x^{10})}(1−x)(1−x5)(1−x10)1​: with ddd dimes (0, 1, 2) the nickels range over 0..⌊(25−10d)/5⌋0..\lfloor(25 - 10d)/5\rfloor0..⌊(25−10d)/5⌋: 6+4+2=126 + 4 + 2 = 126+4+2=12.
    RatMath code
    const den = (k) => discrete.series(Array.from({ length: k + 1 }, (_, i) => (i === 0 ? 1 : i === k ? -1 : 0)));
den(1).multiply(den(5)).multiply(den(10)).reciprocal().coefficient(25)
    Output
    12
