  1. 1.Bézout coefficientsAgrees
    Find gcd⁡(252,198)\gcd(252, 198)gcd(252,198) and integers x,yx, yx,y with 252x+198y=gcd⁡(252,198)252x + 198y = \gcd(252, 198)252x+198y=gcd(252,198).
    Independent answer
    252=1⋅198+54252 = 1\cdot198 + 54252=1⋅198+54, 198=3⋅54+36198 = 3\cdot54 + 36198=3⋅54+36, 54=1⋅36+1854 = 1\cdot36 + 1854=1⋅36+18, 36=2⋅1836 = 2\cdot1836=2⋅18. So the gcd is 18, and back-substituting gives 18=4⋅252−5⋅19818 = 4\cdot252 - 5\cdot19818=4⋅252−5⋅198.
    RatMath code
    numtheory.egcd(252, 198)
    Output
    { g: 18n, x: 4n, y: -5n }
    Every other numtheory function takes plain numbers, but egcd needs BigInts: egcd(252n, 198n) gives { g: 18n, x: 4n, y: -5n }.
    Fix: ratmath/numtheory#9, egcd, gcd, isqrt and friends read any whole number

  17. 17.Frobenius numberAgrees

    Independent answer

  19. 19.Legendre's formulaPartly
    What is the largest power of 2 dividing 100!100!100!?
    Independent answer
    ⌊100/2⌋+⌊100/4⌋+⋯=50+25+12+6+3+1=97\lfloor 100/2\rfloor + \lfloor100/4\rfloor + \dots = 50 + 25 + 12 + 6 + 3 + 1 = 97⌊100/2⌋+⌊100/4⌋+⋯=50+25+12+6+3+1=97.
    RatMath code

    Output
