  1. 1.ProportionsAgrees
    5 pounds of apples cost \$8.75. At the same rate, what do 8 pounds cost?
    Independent answer
    \$1.75 a pound, so \$14.00.
    RatMath code
    R`8.75 / 5 * 8`
    Output
    14
  2. 2.Percent changeAgrees
    A plant grows from 40 cm to 52 cm. What is the percent increase?
    Independent answer
    12/40=0.3012/40 = 0.3012/40=0.30, a 30% increase.
    RatMath code
    R`(52 - 40)/40 * 100`
    Output
    30

  17. 17.Simple probabilityAgrees
    A bag has 3 red, 5 blue and 2 green marbles. One is drawn at random. What is the probability that it is not blue?
    Independent answer
    5/10=1/25/10 = 1/25/10=1/2.
    RatMath code
    stats.finite({ red: 3, blue: 5, green: 2 }, { normalize: true }).prob((c) => c !== "blue")
    Output
    1/2
