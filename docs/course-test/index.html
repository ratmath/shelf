Course Test

How far do the RatMath libraries reach across school and university mathematics? For each course, a twenty-question test of the kind the course sets; answers worked out independently, by hand; and the same test answered with RatMath Core and the Shelf libraries alone. Every question where the two disagree, or the libraries fall short, is listed under Findings.

How the tests were made

  1. The tests. For each course, twenty exercises of the kind a teacher sets in that course, spread over its usual topics. They are ordinary exercises, not chosen to suit the libraries.
  2. Independent answers. Each exercise was answered by hand first, with the working shown, without RatMath. Long arithmetic and the statistical tables were checked a second way, by another method or in Python (SymPy, SciPy), never with RatMath.
  3. RatMath answers. Then each exercise was answered with code that uses only RatMath Core and the Shelf libraries. The code is run whenever these pages are built, and what it prints is compared with the independent answer.
  4. Verdicts. A question is Agrees when the outputs match, Partly when RatMath gets the answer but not all the question asks (a form, a step, a proof, or only a numeric check), and Can't yet when no library has the tool. A disagreement or an error is a finding: either a bug, now fixed or reported, or a convention worth knowing.

The code on these pages uses each library under its own name (linalg, stats, …) with Core's names (R, Rational, …) and Core's units (units.Q) in scope. The Shelf libraries are not yet on npm, so the code boxes here are not live; the outputs shown are those printed when the pages were built (bun run course-tests).
