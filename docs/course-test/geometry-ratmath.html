  11. 11.Centre and radiusPartly
    Find the centre and radius of x2+y2−6x+4y−12=0x^2 + y^2 - 6x + 4y - 12 = 0x2+y2−6x+4y−12=0.
    Independent answer
    (x−3)2+(y+2)2=25(x - 3)^2 + (y + 2)^2 = 25(x−3)2+(y+2)2=25: centre (3,−2)(3, -2)(3,−2), radius 5.
    RatMath code
    const [atom] = graphics.conicAtoms(graphics.parseCondition("x^2 + y^2 - 6x + 4y - 12 = 0"));
graphics.conicType(atom.poly)
    Output
    circle
    graphics recognises the curve as a circle, but nothing returns its centre and radius from the general equation (geo builds circles from a centre and a point; geo.Conic classifies projective conics). Completing the square is done by hand.
